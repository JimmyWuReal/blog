## RULES 

- You only build in the `website` folder unless told to work in `blogs` or `notebooks`. 
- Never touch the `README.md`. 

## GIT 

You shouldn't commit any change in the `blogs` or `notebooks` folders, only website change should be commited unless told different. 

When commiting the commit message should be: 

1. `blog: ???` for blog post or notebook change
2. `website: ???` for website change 
3. `other: ???` for other change 

Also only write commit message in lowercase and short words
