## 複雜度

複雜度（Complexity）是用來評估一段程式或演算法效率與資源消耗的指標，通常會看時間複雜度和空間複雜度

以時間複雜度為例，它描述的是當輸入大小變大時，程式所需的時間會怎麼變化。如果輸入數量 $N$ 變成 $x$ 倍，時間會變成 $x^2$ 倍，時間複雜度就是 $O(N^2)$

複雜度通常用 Big-O 表示，像是 $O(N)$ 或 $O(\log N)$

因為我們只關心 $N$ 很大時時間成長的趨勢，所以寫的時候會：

- 只保留最高次項：$N$ 很大時，低次項跟最高次項比起來小到可以忽略
- 忽略常數：常數不影響成長趨勢，$N$ 變 2 倍時，$N^2$ 和 $3N^2$ 都會變 4 倍

例如 $O(3N^2+2N+1)$ 會寫成 $O(N^2)$

複雜度很重要，才可以避免 `TLE` 和 `MLE`

## 常見複雜度

以下是在不同的複雜度，$N$ 最多可以到多少

也可以記得一秒大概可以跑 $10^8$ 個簡單運算，然後計算來知道，如果超過就會 `TLE`

例如，$N \le 10^5$ 如果複雜度為 $O(N^2)$ 就把 $N=10^5$ 代入，$N^2=10^{10}>10^8$ 所以不行

| 複雜度 | $N$ 的值 |
| --------- | ------ | 
| $O(1)$ 或是 $O(\log N)$ | $N$ 幾乎不受限 |
| $O(N)$ | $N \le 10^8$ |
| $O(N\log N)$ | $N \le 10^6$ |
| $O(N^2)$ | $N \le 5000$ |
| $O(N^3)$ | $N \le 500$ |
| $O(2^N)$ | $N \le 20$ |
| $O(N!)$ | $N \le 10$ |


## 計算複雜度

我們要看迴圈的數量，一個迴圈裡面做簡單運算，重複 $N$ 次為 $O(N)$

如果是分開的迴圈，相加，如下為 $O(N+M)$

```cpp=
for (int i=0; i<N; i++) {
    // ... 
}

for (int j=0; j<M; j++) {
    // ...
}
```

如果是包含在裡面的，要相乘，如下為 $O(NM)$

```cpp=
for (int i=0; i<N; i++) {
    for (int j=0; j<M; j++) {
        // ... 
    }
}
```

然後最後移除常數和低次項就可以了

> 注意：有些 `STL` 的運算像是 `vector` 的 `sort` 並不是 $O(1)$，而是 $O(N \log N)$，需要把它算進去，用跟迴圈一樣的邏輯
